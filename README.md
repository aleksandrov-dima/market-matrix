# market-matrix

Статический каталог приложений Store: около 119 тысяч приложений и их цены по 241 рынку (стране).

Сайт: https://aleksandrov-dima.github.io/market-matrix/

- Таблица с поиском, фильтрами и выгрузкой в CSV; выбор рынка показывает цены и доступность в этой стране.
- Карточка приложения — цены по всем рынкам.
- Поиск идей: над таблицей — полоса «Идеи / Спрос». При пустом поиске — ниши рынка по пресетам («Всё зелёное», «Слабые лидеры», «Пустые ниши», «Растут», «Платят»), при заданном — спрос по запросу (частотность Google, тренд, CPC, Score) и вывод; таблица — конкуренты. Справка с примерами — кнопка «Как искать идеи».
- Работает без сервера: страница (`index.html`) читает JSON-файлы из `data/` и сама распаковывает `.gz` в браузере.

## Данные

- Каталог и цены — снимок, собранный 30 сентября – 1 октября 2026 г.
- Спрос — Google Keyword Planner (поиск в Google, не в Store), собран 8–9 октября 2026 г. для 10 рынков: US, GB, MX, BR, FR, DE, JP, IN, SA, TW (`data/niches/`).

Данные не обновляются автоматически: цены, доступность, состав каталога и частотность запросов могли измениться с тех пор.
