# market-matrix

Статический каталог приложений Store: около 119 тысяч приложений и их цены по 241 рынку (стране).

Сайт: https://aleksandrov-dima.github.io/market-matrix/

- Таблица с поиском, фильтрами и выгрузкой в CSV; выбор рынка показывает цены и доступность в этой стране.
- Карточка приложения — цены по всем рынкам.
- Работает без сервера: страница (`index.html`) читает JSON-файлы из `data/` и сама распаковывает `.gz` в браузере.

## Данные

Данные — снимок, собранный 30 сентября – 1 октября 2026 г. Они не обновляются автоматически: цены, доступность и состав каталога могли измениться с тех пор.
