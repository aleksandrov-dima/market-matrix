Как искать идеи для приложения

Над таблицей приложений — полоса, которая соединяет спрос (сколько людей ищут задачу в Google) с предложением (какие приложения уже есть в Store).

  • Поиск пустой → «Идеи». Список ниш выбранного рынка с пресетами: «Слабые лидеры», «Пустые ниши», «Растут», «Платят», «Все по Score».
  • Поиск задан → «Спрос». Сводка спроса по запросу, автоматический вывод и ключи; таблица ниже — конкуренты по тому же запросу.

Пример: идея «окно поверх других окон» (аналог WindowTop)

  1. Рынок US, в поиске "always on top" (кнопка «Пример проверки идеи» внизу) — в кавычках, чтобы и спрос, и конкуренты искались точной фразой (без кавычек каталог ищет слова по отдельности, и top найдёт «Desktop»). Всё подставится само.
  2. Полоса «Спрос»: около 1,8 тыс. запросов в месяц по ключам с этой фразой (always on top windows 11, powertoys always on top…), за год −24%, CPC $0 — за эту тему никто не платит рекламе.
  3. Вывод собирается автоматически: «спрос средний», «спрос падает», «за рекламу почти не платят»; Score — средний для рынка.
  4. Ключи под сводкой: лишние (например, always on top mac) щелчком исключаются из суммы.
  5. Таблица — конкуренты с этой фразой в названии или описании (около 30); отсортируйте по «Оценок». Лидер рынка WindowTop (★4,8, 685 оценок, $21,99) сюда не попал — в описании у него «set the window on top»: найдите его запросом windowtop. Конкурентов ищите несколькими формулировками. Щелчок по строке — карточка с ценами по всем странам.
  6. Попробуйте синонимы: keep window on top, pin window, ontopreplica — спрос ниши складывается из нескольких формулировок.
  7. Итог примера: ниша маленькая и сужается, лидер сильный, а бесплатный Microsoft PowerToys закрывает основу задачи. Для сравнения откройте пресет «Слабые лидеры» при пустом поиске — там ниши с Score в разы выше.

Какую идею искать

Цель — ниша, где все метки вывода зелёные: спрос большой и не падает, за рекламу платят (значит, аудитория чего-то стоит), лидеры в Store слабые, Score в верхних 30% рынка. Для этого есть пресет «Всё зелёное»: в нём только ниши, где приложения в Store уже есть, но слабые, — спрос именно на программу подтверждён, а обойти лидеров реально.

«Пустые ниши» (приложений нет) — не то же самое: наверху там чаще бренды и веб-сервисы (xe currency converter, desmos calculator), которые закрывают спрос без приложения. Их стоит проверять вручную.

Пример 2: поиск идеи

  1. Рынок US, поиск пустой, пресет «Всё зелёное». Можно нажать «Пример поиска идеи» внизу.
  2. В списке, например, voice recorder with transcription: около 22 тыс. запросов в месяц, +83% за год, CPC около $8, в каталоге одно подходящее приложение и почти без оценок.
  3. Щелчок по строке: полоса покажет спрос по нише, таблица — конкурентов, отсортированных по числу оценок. Точной фразы нет ни в одном листинге, поэтому запрос подставится словами: voice recorder transcription. Проверьте синонимы ("transcription app", "speech to text") — ниша обычно шире одной формулировки.
  4. Вернуться к списку идей — кнопка «← к идеям» на полосе или «Назад» в браузере.
  5. Дальше — вручную: что предлагают конкуренты, почему у них мало оценок, нужен ли для задачи именно Windows.

Поиск идей

  1. Очистите поиск, выберите рынок и пресет: «Всё зелёное» — главный кандидат, «Слабые лидеры» — шире, без условий на тренд и рекламу.
  2. Щёлкните по нише — она станет запросом: в кавычках (точная фраза), а если фразы нет ни в одном листинге — значимыми словами. Увидите её спрос и конкурентов, отсортированных по числу оценок. «← к идеям» возвращает список с прежним пресетом и сортировкой; «Сбросить» в шапке очищает всё, включая фильтры слева.
  3. На неанглийских рынках ключи местные (≈ — английский эквивалент): запрос подставляется по-английски, потому что листинги в каталоге английские, а спрос показывается по местным ключам.

Что означают цифры

Запр./мес
Среднее число поисков в Google за 12 месяцев (Google Keyword Planner, округлено корзинами).
Тренд
Последние 3 месяца к среднему за год: ≥ 1,2 — растёт, ≤ 0,8 — падает.
CPC
Сколько рекламодатели платят за клик (80-й перцентиль). Около $0 — коммерческой ценности почти нет; от $2 — за аудиторию платят.
Оценок топ-5
Сумма оценок у 5 самых оценённых приложений каталога со словами ключа: < 500 — лидеры слабые, > 20 000 — ниша занята.
Score
Сводная оценка ниши: спрос × готовность платить × слабость лидеров / сила конкурентов. Перцентиль — какая доля ниш рынка ниже.
≈
Конкуренты подобраны по английскому эквиваленту местного ключа.

Ограничения

  • Спрос — это поиск в Google, а не в Store: частотность поиска в Store Microsoft не публикует. Это прокси, а не прогноз установок.
  • Данные собраны по ~600 типовым задачам (англ.) и ~170 переведённым; ниш вне этого списка может не быть — проверку произвольных идей добавим позже.
  • Спрос: "фраза в кавычках" и запрос со служебными словами (always on top, picture in picture) ищутся в ключах целиком как фраза, остальные запросы — каждое слово целым словом в любом порядке. Совпадение текстовое: pin window найдёт и «resetting pin windows 10». Лишние ключи исключайте щелчком.
